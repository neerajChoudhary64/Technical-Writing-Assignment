This repository contains documentation and practical learning of **Technical Writing (TW)** .

The repository covers six major topics: LaTeX, Beamer, Doxygen, Google Docs, Git, and GitHub.

## Topics Covered

### 1. LaTeX
LaTeX is a document preparation system used to create professional documents, technical reports, research papers, and academic assignments.

[Read LaTeX Documentation](LaTeX/latex.md)

### 2. Beamer
Beamer is a LaTeX document class used to create professional presentations and slides.

[Read Beamer Documentation](Beamer/beamer.md)

### 3. Doxygen
Doxygen is a documentation-generation tool that creates documentation from source code and specially formatted comments.

[Read Doxygen Documentation](Doxygen/doxygen.md)

### 4. Google Docs
Google Docs is an online word-processing application used to create, edit, format, and collaborate on documents.

[Read Google Docs Documentation](Google-Docs/google-docs.md)

### 5. Git
Git is a distributed version control system used to track changes in files and manage different versions of a project.

[Read Git Documentation](Git/git.md)

### 6. GitHub
GitHub is a web-based platform used to host Git repositories and collaborate on software development projects.

[Read GitHub Documentation](GitHub/github.md)
